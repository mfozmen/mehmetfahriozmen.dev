# mehmetfahriozmen.dev

The personal site of Mehmet Fahri Özmen, a backend systems architect and engineering leader based in İzmir.

**[mehmetfahriozmen.dev](https://mehmetfahriozmen.dev)**

## What's there

- **[Field Notes](https://mehmetfahriozmen.dev/writing)**: essays on engineering leadership, planning, AI and building software
- **[Lab Day](https://mehmetfahriozmen.dev/lab)**: hands-on technical guides
- **[About](https://mehmetfahriozmen.dev/about)** and **[CV](https://mehmetfahriozmen.dev/cv)**: the story and the timeline
- **[Contact](https://mehmetfahriozmen.dev/contact)**

The homepage maps the systems I've built as a small galaxy. Hover a star to see what it was.

## Built with

Next.js, React, TypeScript and Tailwind CSS, deployed on Vercel.
